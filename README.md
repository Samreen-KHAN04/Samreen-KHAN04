## 🚀 Featured Projects

### 📚 [StudyBuddy — AI-Powered EdTech Platform](https://github.com/Samreen-KHAN04/AI-Studdy-Buddy) *(Major Project)*
Full-stack platform that converts PDFs into quizzes and audio using **Llama 3.3 (Groq API)**, with **SM2 spaced-repetition** scheduling for automated weak-area detection. Deployed on Streamlit Cloud; handles 50+ page documents at **sub-5s response latency**.

`Flask` `Llama 3.3` `Groq API` `Python` `SM2`

<br/>

### 📄 [Automated Resume Screening Tool](https://github.com/Samreen-KHAN04/AI-resume-screening-tool)
NLP-based candidate ranking system that parses PDF/DOCX/TXT resumes and extracts **100+ skills**. Scores candidates with a weighted TF-IDF + cosine-similarity model (40% content, 40% skills, 20% experience); cut manual screening time by **~90%** in internal testing on a sample resume set.

`Python` `NLP` `TF-IDF` `Cosine Similarity` `Streamlit`

<br/>

### 📈 [Retail Inventory & Demand Forecasting System](https://github.com/Samreen-KHAN04/Retail-Sales-Forecasting-System)
Time-series ML pipeline with lag features for demand forecasting. Computes **Safety Stock & Reorder Points at a 95% service level**, with a single-page command center that automates bulk risk screening across SKUs.

`Python` `Random Forest` `Streamlit` `Plotly`
